# ai-coustics Speech Enhancement SDK

- This is the C-Interface to our library and the entrypoint for all other wrappers

If you are looking for other languages check out:
- `aic-sdk-cpp`
- `aic-sdk-py`
- `aic-sdk-node`
- `aic-sdk-wasm`

- In the releases you will find the prebuilt binaries as static and dynamic libraries for multiple operating systems and architectures
